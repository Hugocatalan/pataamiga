# PataAmiga — Veterinaria & Pet Shop

¡Bienvenido al repositorio de **PataAmiga**! Este es el sitio web que diseñé y desarrollé para una veterinaria y tienda de productos para animales, pensado para brindar una experiencia moderna, cercana y accesible a los dueños de mascotas.

**Sitio web en vivo:** [https://hugocatalan.github.io/pataamiga/](https://hugocatalan.github.io/pataamiga/)

---

## 🐾 Sobre el proyecto

El objetivo principal al crear este proyecto fue construir una presencia digital sólida, profesional y confiable para una veterinaria en Santa Fe, Argentina. Me enfoqué en:
- Una interfaz limpia y cálida, con una paleta de colores natural (verdes profundos y tonos crema).
- Navegación fluida y adaptada tanto a computadoras como a teléfonos móviles.
- Comunicación directa mediante WhatsApp para coordinar turnos y consultas de productos.
- Especial atención al bienestar animal y a la nutrición balanceada de perros y gatos.

---

## 🚀 Tecnologías utilizadas

- **React 19** con **Vite** para una carga ultrarrápida y componentes modulares.
- **CSS3 moderno** con variables nativas, animaciones suaves y diseño responsive.
- **Phosphor Icons** para una iconografía limpia y coherente.
- **Google Fonts** (tipografías *Nunito* y *DM Sans*).
- **GitHub Pages** para el despliegue automático del sitio.

---

## ✨ Secciones principales

1. **Portada (Hero):** Bienvenida cálida con mascotas felices y barra rápida de confianza profesional.
2. **Servicios veterinarios:** Consultas clínicas, vacunación, controles de salud preventivos, odontología e higiene, con ventanas modales para ver detalles.
3. **Pet Shop & Nutrición:** Sección orientada a alimentos saludables, snacks balanceados y accesorios cotidianos.
4. **Diferenciales:** Pilares de atención personalizada y un espacio libre de estrés.
5. **Historias & Galería:** Galería optimizada para mostrar a los pacientes y animales que nos inspiran.
6. **Especialistas en Nutrición:** Enfoque clínico en planes dietarios y fórmulas premium para cada etapa de vida.
7. **Contacto & Ubicación:** Información clara de horarios, dirección provisional en Santa Fe, enlace directo a Google Maps y botón de WhatsApp.
8. **Barra móvil inferior:** Acceso inmediato a *Pedir turno* y *WhatsApp* desde cualquier parte de la navegación en celulares.

## 🛠️ Instalación y desarrollo local

Si querés clonar este proyecto y probarlo en tu máquina:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Hugocatalan/pataamiga.git
   cd pataamiga
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor local:**
   ```bash
   npm run dev
   ```
   Abrí `http://localhost:3000` en tu navegador.

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

5. **Desplegar cambios a GitHub Pages:**
   ```bash
   npm run deploy
   ```
